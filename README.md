## Tasks

### Q1 - Temperature Converter
Converts temperature between Celsius and Fahrenheit. Shows the answer rounded to 1 decimal place and warns when the input is empty or not a number.

### Q2 - FizzBuzz
Generates a FizzBuzz list up to the upper limit chosen by the user.

### Q3 - Student Records
Displays student records, grades, class average and top scorer.
Includes the bonus button that sorts the table by marks from highest to lowest.

### Q4 - Counter and Theme Switcher
Includes a counter with +1, -1 and Reset (never goes below 0) and a Dark/Light Mode toggle.
